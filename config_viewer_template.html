Passwords, SNMP communities, keys and similar secrets are replaced with <redacted:xxxx> before this page is built. The four characters change when the secret changes, so a changed secret still shows up as a change without revealing it. Device-reported “changed by” is only as good as the device: it is the last change only, IOS shows a user only for logged-in sessions, and NX-OS shows none.
